Weekly tidy-up of what the team remembers. No Keboola calls, no SQL: files under /memories/ and /knowledge/ only.

1. Shared memory (/memories/AGENTS.md, which every run reads): merge duplicates, drop facts that a project profile in
   /memories/projects/ now covers in more detail (keep the one-entry pointer per project under `## Projects`),
   remove one-off details and anything outdated, and keep the user's preferences and conventions. Aim for under
   60 lines. Never drop a fact you cannot see elsewhere unless it is clearly obsolete; move longer explanations to
   the knowledge base instead of deleting them.
2. Knowledge base: have knowledge-keeper file notes the user uploaded at the top level into its layout, merge
   duplicates and fix broken links between notes. Notes under /knowledge/data-model/ are generated by init
   workspace: leave them as they are.

Report in up to five lines: what was merged, moved or removed, and anything that looked contradictory and needs the
user's decision.
